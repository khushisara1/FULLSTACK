# Full Stack Learning Projects

This project contains my journey through full-stack development. It includes small, practice-focused projects that help me learn HTML, CSS, JavaScript, layouts, responsive design, and basic web interactions.

## Included Pages

- `bento.html` - Simple blue bento-box layout
- `box.html` - Responsive travel photo gallery
- `dashboard.html` - Dashboard with sidebar, navigation, and metric cards
- `nav.html` - Responsive navigation bar
- `newpaper.html` - Newspaper-style travel page
- `old.html` - Welcome page with a travel background
- `photogallery.html` - Responsive bento photo gallery
- `power_card.html` - Two colorful power cards
- `product.html` - Product page practice
- `login.html` - Login page practice
- `font.html`, `grid.html`, `Tailwind.html`, and other files - Layout and styling experiments

## Folders

- `images/` - Images used by the gallery and page examples
- `fonts/` - Font files used for practice
- `javascript/` - JavaScript examples and small interactive projects

## How To Run

Open any `.html` file directly in a browser, or use the **Live Server** extension in VS Code for automatic browser refresh while editing.

## Learning Goals

- Build clean page layouts with HTML and CSS
- Practice CSS Grid and Flexbox
- Create responsive designs for different screen sizes
- Add simple JavaScript interactions
- Improve design by experimenting with colors, spacing, and typography
